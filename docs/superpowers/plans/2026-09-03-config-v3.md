# FutsalMOT Config v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增简洁、可跨机器复用的单 episode Config v3，并由 resolver 生成旧 pipeline 可直接消费的完整 `resolved_task.json`。

**Architecture:** 在现有 v2 `DatasetTaskConfig` 前增加 v3 用户配置模型和 local machine config loader；resolver 负责将单一来源的 FPS、resolution、camera mapping、annotations、classes 展开到旧版 export/UE/postprocess/audit 字段。P1/P2 保持读取 resolved task 的现有接口，v2 继续走旧路径并给出 deprecated warning。

**Tech Stack:** Python 3.9、Pydantic、Typer、JSON、pytest、Unreal Engine 5.8 existing task pipeline。

**Spec:** `docs/superpowers/specs/2026-09-03-config-v3-design.md`

## Global Constraints

- 本次只处理单 episode 配置，不实现 batch、train/val/test split、dataset assembler、Camera Manager、动画、motion preprocessing、新 MRQ 功能或 public GT 格式调整。
- Config v3 用户层不包含 `dataset_root`、`ue_project_root` 或其他机器绝对路径。
- local config 选择优先级固定为：`--local-config`、`FUTSALMOT_LOCAL_CONFIG`、无配置则报错；不自动搜索 task 同目录文件。
- local config 只保存机器相关路径/环境信息，不混入 episode、camera、FPS、resolution、annotations、classes 或 debug。
- v3 validate/resolve 在 local config 缺失、路径不存在、UE project 缺少 `.uproject` 时立即失败，不写半完整 resolved task。
- `resolved_task.json` 保留旧 `futsalmot_resolved_task` schema 和完整内部字段，public output contract 不变。
- v2 兼容读取并输出 deprecated warning；不得删除旧配置能力。
- 代码注释、文档字符串、文档和 Pydantic 描述使用简体中文；不自动 push。
